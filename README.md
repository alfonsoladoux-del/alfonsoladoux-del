**Python + Pandas + SQL + MySQL + Power BI**

End-to-end data analysis project exploring a meteorite dataset.

The project includes data cleaning, exploratory analysis, SQL queries, and Power BI visualization to identify historical patterns and geographic trends.

**Key findings include:**

* Around 97% of the recorded meteorites were classified as "Found" rather than "Fell".
* The number of records increased significantly between 1980 and 2000.
